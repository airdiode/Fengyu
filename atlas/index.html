使用帮助

地图操作 · 卡片与详情 · 键盘

地图

  • 缩放：滚轮；平移：按住拖动；回全国：双击地图空白处，或点「图层」里的重置。
  • 换年份：拖底部时间轴，或按 ←/→ 一年、Shift+←/→ 十年；打开时停在 1840 年。鼠标在时间轴上移动时，会先显示该位置对应的年份（虚线预览，点一下才跳过去）。
  • 展开时间轴：底部平时只留主进度条，鼠标移上去（或点「展开时间轴」）向上展开年号、时期与灾荒条，移开自动收起。
  • 搜索：顶栏输入人物、事件、地点（/ 聚焦），可按类型与事件类别筛选，命中项在图上高亮并对准镜头。
  • 图层：右上「图层」菜单开关山川、水系、城市、国名、势力范围、主张国境线、黄河故道、贸易航线、1934 校准图等。
  • 比例尺：左下角横杠 + 年份行。比例按视图中心纬度算（墨卡托高纬放大，跨 36° 纬度的全国图上下差约 15%），缩放时按 1/2/5 档跳。
  • 灾荒条：时间轴最下面一排竖条是 1840–1911 的逐年报灾条数（据《中国三千年气象记录总集》第四册，OCR 抽取），颜色是当年最多的灾种；换年时左上角会跳出「本年灾情」小结。

卡片与详情

  • 悬停：鼠标移到点、线、边界或区域上，右侧弹出摘要卡（正文最多三行），底部提示「点击展开详情」。
  • 人物点：实心点是籍贯/出生地，空心点是某一年的活动地（只在对应年份出现，名字也跟着走）；详情顶部会列出「籍贯/出生地 · 活动地」。
  • 点开：点一下展开详情卡。事件、人物是完整条目（含参考出处）；国境线、割让面、势力范围、租界与控制区则是说明加「数据源与精度」附注。
  • 收起：详情卡展开后摘要卡自动收起。这时鼠标扫过别的点，只在鼠标旁点一个只写标题的小标签，不挡卡片。
  • 关闭：点地图空白处、按 Esc，或点详情卡右上角的 ×。
  • 返回专题：从专题列表点进某个成员后，详情卡顶部有「← 返回专题 · …」，点一下回到刚才的章节列表。

关于「风雨如磐」

1840–1949 年中国近代史读史地图 · v2 · 2026-11

项目简介

「风雨如磐」把 1840–1949 年的疆域、事件、人物、机构、路线放在一张可拖动的地图上。名字取自鲁迅 1903 年《自题小像》：「灵台无计逃神矢，风雨如磐暗故园。」

它不是游戏，也不是边界测绘：底图固定为 1840 年清朝实控基线，1858 年以后的割让、占领、租借、傀儡政权与势力范围用叠加层表达；虚线是当时中央政府的主张国境，实线是实控与割让，两者不一致处（1912–1946 外蒙、唐努乌梁海，1895–1945 台湾）分开表示。

怎么读

时间轴、搜索、悬停摘要、点开详情、图层的具体用法都收在顶栏的「帮助」里（按 ? 也能打开）。

    制作方式

    • 内容写在 data/*.json，经 tools/migrate.mjs 与旧项目数据合并；tools/normalize.mjs 合并重复条目、校正类别、收敛标签；pnpm validate 校验、pnpm test 回归。
    • 地图是 TypeScript + Canvas 2D，没有框架和打包器；标注由独立求解器排布（贪心 + 局部回溯）。
    • 地理图层由 tools/ 下的 Python / Node 管线从公开数据生成，可复现。条目与出处数在页面加载时统计。

    难点与局限

    • 边界没有测绘底本。1840 基线是示意性复原：西段（卡伦线、帕米尔、藏南）按《清史地图集》和 1934 年《中华民国新地图》手工修过，仍是 0.1° 级；东段外东北按现代中俄边界裁，再用割让面表示「未承认的割让」。不能当测绘线用。
    • 割让面与占领区多为描线/手绘。伊犁西界依《清史地图集》p.152 描线，瑷珲、乌苏里、西北界约按条约文字和旧图取界；不同史料对同一条界线有异说，图上取其一。
    • 主张与实控分开，但不做裁判。1912–1946 的外蒙、唐努乌梁海，1895–1945 的台湾，都按「当时中央政府怎么说」画成虚线，和实控分开；1946 年承认外蒙独立后仍按当时说法处理。这是史实呈现，不是法律判断。
    • 内容远非全集。战争细节、地方史、边疆、女性与日常生活覆盖不均；部分旧迁移条目出处是二手，已尽量补权威/一手来源，但做不到每条都核对原档。
    • 分类是规则+人工。事件 10 类先按关键词分，再人工校正；边界事件（兵变、政变、涉外冲突）仍可能归错。标签已收敛，但长尾仍在。
    • 标注会挤。长三角、京津冀、广州这些密集区，求解器只能保证「已放下的不重叠」，放不下的会被挤掉或缩短，不能保证每个点都有字。
    • 技术边界。Canvas 2D、无 WebGL、无播放、无 3D；移动端未专门适配；1840 年以前不通史回填。

    反馈与投稿

    发现某条史实有误、出处不对、地图画错，或者手上有更可靠的资料——都欢迎告诉我们。站内表单会自动带上条目编号、年份与数据版本，省得来回问。

    • 纠错：点开任意一条的「这一条有误？」，或页脚的「报错与投稿」。配好后可直接在页面提交，反馈会公开出现在项目的 GitHub issue 列表里，处理后会在提交记录里写明。
    • 资料与建议：写到 contact@airdiode.com；长篇材料、扫描件、书目都走这个邮箱。
    • 请别在反馈里写个人信息。公开的 issue 谁都能看见；联系方式一格可以不填。
