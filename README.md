# 风雨如磐 — 项目主页

「风雨如磐」的公开预告页，对应 <https://airdiode.github.io/Fengyu/>。
纯静态站（GitHub Pages），没有构建步骤，改完 HTML/CSS 直接推。

## 这是什么

一个近代中国（1840–1949）的信息底图的项目主页。现在只放来说明、截图与进度——
地图与检索尚未公开。产品本体在另一个仓库（暂未公开），这里只托管这一页。

## 文件

```
index.html        唯一页面（中文）
styles.css        全部样式：纸色底、墨色字、赭石强调、宋体标题，含深色模式
assets/mark.svg   站点标记（山形线稿）与 favicon
assets/og.png     分享卡片 1200×630
assets/hero.jpg   首屏截图（1900 年界面）
assets/labels.jpg 1935 年长三角：标签与引线
assets/reader.jpg 专题读页：条约体系
assets/panel.jpg  1907 年女子学堂章程的详情页与指标
```

图片都来自产品截图，裁切压缩后用；换图直接覆盖同名文件即可（保持宽高比接近原图）。

## 改内容时注意

- **数字要与产品同步**：1,532 条目、736 出处、208 条人物关系、10,267 条县级报灾、23 专题 103 章。
  这些数写在 `index.html` 的首屏 `stats`、`numbers`、以及 `assets/og.png` 里，改数要三处一起改。
- **口径不能软**：边界写「重建与示意，不是测绘」；有争议处并列「主张 / 实控」；
  给不出页码的出处只写书名——这几句在「开放与说明」一节里，别删。
- **不写没有的事**：民国部分只写「刚起步」，不要写成已完成。
