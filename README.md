# 风雨如磐 · 近代中国的信息底图

一个 1840–1949 年的中国近代史信息底图：疆域按年切换，事件、人物、机构、灾荒、报刊、铁路各归其位，每条都带着出处。

**在线**

- 站点与说明：<https://airdiode.github.io/Fengyu/>
- 地图应用：<https://airdiode.github.io/Fengyu/atlas/>

## 现在有什么

- **2,091 条实体**：事件 574、人物 1,061、机构 131、组织 47、群体 43、专题 33，另有技术、作品、地点、路线、战线、疆域等；**1,139 条出处**，每条实体都能回到来源。
- **33 条专题线**：从鸦片战争到 1949 年的名单，每条线是一篇可读的文章，章节有导语，成员有一句提要。
- **612 个「可以去看看」的实地点位**：故居、墓葬、遗址、纪念馆、条约正本，带地址与文保级别。
- **疆域**：1840 年基线分三档（直辖 / 藩部 / 主张未实控）；1864、1881 割让面；租借地、势力范围、军事占领分层；1934 年《申报》地图配准后替换了海岸与东北的线。
- **灾荒**：1840–1911 共 10,267 条县级报灾记录（水、旱、蝗、疫、震），按省统计，点县看它七十年。

## 怎么读

1. **拖时间轴换年份**：疆域、割让面、势力范围随时间改变；方向键换一年，Shift + 方向键十年一跳。
2. **搜一条**：顶栏输入人物、事件、地点，或按 / 聚焦；结果标出命中片段。
3. **点开任意一条**：详情里有摘要、出处、相关人物、指标与「可以去看看」的点位；关系可点，能顺着走。
4. **逛专题**：顶栏「专题」是按内容分组的 33 条线；每条线能当文章从头读到尾。

## 仓库结构

```
index.html      官网（内容说明、截图、致谢）
styles.css      样式（纸色底、赭石强调、宋体标题）
assets/         标记、分享卡、截图
atlas/          地图应用（运行产物）
  ├─ index.html
  ├─ dist/      编译后的 JS/CSS
  ├─ content/   内容分片与 bundle.json
  └─ public/    地理 JSON
```

**atlas/ 是构建产物，不要在这里手改**——改源码后由本地构建、再用发布脚本同步进来（见产品仓库的 docs/deploy.md）。

## 反馈与投稿

- **纠错**：在地图里点开任意一条，末尾有「这一条有误？」；或点页脚「报错与投稿」。表单会自动带上条目编号、年份与数据版本。
- **资料与建议**：<contact@airdiode.com>。长篇材料、扫描件、书目都走这里。
- **GitHub**：也可以在 Issues 里提。

处理过的反馈会在提交记录里写明；发现错误请连依据一起说（书页、档案、链接），这样改起来最快。
